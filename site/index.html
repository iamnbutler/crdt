THE CHANGE

Compress the storage.
Keep the identities.

Consecutive typing shares a run. Every character keeps its own stable identity, so splitting or combining a run cannot change how replicas merge.

A splay tree keeps recent edit positions close. Separate indexes locate remote references and order concurrent siblings without walking the whole document.

Read the design ↗
THE CURRENT LIMITS

A text engine.
An experiment.

These measurements cover plain text on the displayed runtime and machine. They do not establish a universal winner. Encoding size, loading, and editing speed are separate tradeoffs.

RunText has sync, persistence, and stable anchors. Rich text, an undo manager, history reclamation, and constant-time snapshots are still open work. RGA ordering also has different interleaving behavior from FugueMax.

03 / KEEP THE EXPERIMENT HONEST

Reproduce it. Inspect it. Improve it.

Same work

The full Kleppmann trace uses one bulk transaction. Synthetic edits and the 10,000-edit live trace commit individually. No observers or editor integrations are attached.

Real state

Encoding retains collaboration state. Loading creates a usable replica and reads its text. Yjs uses compact update V2. State sizes use native formats without extra transport compression.

Checked output

Each measured edit sequence must match its exact expected text. Decoded state must match too, and merging peers must converge. An incorrect result receives no timing rank.

Visible evidence

Five samples follow one full warmup. Fresh processes isolate libraries; measurements run sequentially. Every run records its source hash, dependency versions, hardware, fixture hash, and individual samples.
